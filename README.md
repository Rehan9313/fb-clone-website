# fb-clone-website

A practice **Facebook Clone Website** created to learn and demonstrate web development concepts, Git, GitHub, version control, and project deployment.

This project recreates the basic look and feel of a social media platform inspired by Facebook. It is intended **for educational and practice purposes only** and is not affiliated with or endorsed by Facebook/Meta.

## 📌 About the Project

The **fb-clone-website** is a front-end practice project designed to replicate some of the common features and visual elements found on modern social media websites.

The main purpose of this project is to gain practical experience with:

* Building a website structure
* Designing a social-media-style user interface
* Working with HTML, CSS, and JavaScript
* Managing source code with Git
* Using GitHub for version control
* Creating and managing repositories
* Making commits and tracking changes
* Working with branches
* Pushing code to a remote repository
* Understanding a basic web development workflow

This project can also be used as a starting point for adding more advanced functionality such as authentication, databases, APIs, user profiles, posts, comments, and messaging.

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

Open your terminal and run:


### 2. Navigate to the Project

## 🔧 Git Workflow Used in This Project

This project is also intended to provide practice with Git and GitHub.

### Initialize Git

If Git has not already been initialized:

```bash
git init
```

### Check Repository Status

```bash
git status
```

### Add Files

```bash
git add .
```

### Create a Commit

```bash
git commit -m "Initial commit"
```

### Add Remote Repository

```bash
git remote add origin https://github.com/your-username/fb-clone-website.git
```

### Push to GitHub

```bash
git branch -M main
git push -u origin main
```

After making changes, the normal workflow is:

```bash
git add .
git commit -m "Update website"
git push
```

## 🌱 Branching Practice

Branches can be used to experiment with new features without directly modifying the main branch.

Create a new branch:

```bash
git checkout -b feature/new-feature
```

Make your changes and commit them:

```bash
git add .
git commit -m "Add new feature"
```

Push the branch:

```bash
git push -u origin feature/new-feature
```

The branch can then be reviewed and merged into the `main` branch.
